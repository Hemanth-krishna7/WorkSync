# WorkSync

A modern workforce availability management dashboard built with Flask and SQLite.

WorkSync helps teams track employee availability in real time through a clean and responsive interface. Managers can quickly monitor workforce status, filter employees by department, search team members, and update availability instantly.

### Live Demo

https://worksync-667u.onrender.com

---

## Features

* Real-time availability tracking
* One-click status updates
* Employee search and department filtering
* Live workforce statistics
* Recent activity monitoring
* Dark mode support
* Responsive dashboard design
* Automatic database initialization and data seeding
